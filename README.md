# Diva Clinic AI Skin Analysis

A premium clinic website demo combining guided cosmetic skin screening with appointment booking.

## Live Demo

- GitHub Pages: https://kairaio.github.io/diva-clinic-ai/
- Repository: https://github.com/kairaio/diva-clinic-ai

## Features

- Responsive Diva Clinic landing page
- Three-step AI skin analysis simulation
- Guided skin concern selection
- Cosmetic screening summary and scores
- Consultation recommendation
- Appointment date and time selection
- Automatic deployment through GitHub Actions

> The current AI analysis is a clearly labelled demonstration for cosmetic screening. It is not a medical diagnosis.

## Local Development

```bash
npm ci
npm run dev
```

## GitHub Pages Deployment

Every push to the `main` branch automatically builds the static Next.js export and deploys it to GitHub Pages using `.github/workflows/deploy-pages.yml`.
